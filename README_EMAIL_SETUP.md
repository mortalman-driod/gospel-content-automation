# Email Dispatcher Configuration
# To send live emails via Gmail:
# 1. Go to your Google Account -> Security -> 2-Step Verification -> App Passwords
# 2. Create an App Password for "Mail" (16 characters)
# 3. Set the environment variables in your system or your shell profile:
#
# setx SMTP_USER "your_email@gmail.com"
# setx SMTP_PASSWORD "your_16_character_app_password"
# setx SMTP_HOST "smtp.gmail.com"
# setx SMTP_PORT "587"
